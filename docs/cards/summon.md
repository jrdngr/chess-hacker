# Summon cards

Summon cards create new pieces on empty squares.

> **Status:** the prototype currently has no Summon cards. The Soul family
> (Pawn / Knight / Bishop / Rook Soul) used to live here as summons, but was
> repurposed into [Movement-extension](movement-extension.md) cards that
> permanently grant a movement pattern to one of your pieces. This file is
> kept as a placeholder for future summon cards.
