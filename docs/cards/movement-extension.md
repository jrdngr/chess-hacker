# Movement-extension cards

Movement-extension cards give one of your pieces an additional movement pattern for the turn. They keep the piece's normal moveset and add a new option on top.

See [`keywords.md`](keywords.md) for keyword definitions, especially **Empower**.

## Crooked Path

- **Cost:** 1
- **Rarity:** Common
- **Target:** own piece
- **Effect:** Target own piece: **Empower** with knight L-shape as an additional movement pattern this turn.
- **Design note:** the introductory Empower card — turns any piece into a temporary knight. Most interesting on rooks and bishops (suddenly threatens forks) and on pawns (a one-turn jump break). The empowered move is a knight L, so it ignores blockers like a real knight.
